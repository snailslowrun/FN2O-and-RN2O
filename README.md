# FN2O-and-RN2O
R scripts for the analysis of FN2O and RN2O meta-datasets. 
FN2O: the fraction of N2O emitted from nitrification.
RN2O: the N2O/(N2O+N2) ratio. 
The first part of the script is for the FN2O metadata, and the second part for the RN2O metadata. Please ensure to install and load all necessary packages!
